How enrolment works
  1. Issue a token below. The full token is shown once — only its hash is stored.
  2. Download the agent script and run it on the endpoint with the token.
  3. The agent exchanges the token for its own key, then reports inventory on a schedule.
  4. Link the enrolled endpoint to an asset in the register to keep custody and warranty data together.
